# 제품 개요

## 해결하려는 문제

메이플스토리 웹 경매장에서 장비를 비교하고, 환산 주스탯의 아이템메이커에서 가상 장비 조합을 구성하는 과정은 반복 입력이 많습니다. 이 확장 프로그램은 경매장 찜 목록에 담은 장비 데이터를 읽어 환산기 아이템메이커 형식으로 변환하고, 브라우저 안에서 바로 추가할 수 있게 돕습니다.

또한 여러 캐릭터를 다루는 사용자가 환산기 장비 세트를 보관하고 다시 적용할 수 있도록 보관함을 제공하며, 환산기에서 조회한 스펙업 데이터를 조건에 맞춰 정리합니다.

## 지원하는 작업

### 경매장 찜 목록을 아이템메이커에 추가

메이플스토리 웹 경매장 찜 목록을 방문하면 확장 프로그램이 환산 계산 대상 슬롯의 장비를 브라우저 저장소에 동기화합니다. 팝업에서 원하는 항목을 선택하면 아이템의 옵션·잠재능력·스타포스 등의 데이터를 환산기 아이템메이커 형식으로 변환해 추가합니다.

현금 아이템과 환산 계산 대상이 아닌 슬롯은 목록에서 제외됩니다. 찜을 해제했거나 판매가 종료된 항목은 팝업에서 상태로 표시되므로, 내보내기 전에 확인할 수 있습니다.

### 환산기 장비 보관함

환산기에서 현재 내 장비 또는 아이템메이커 보관함을 가져와 확장 프로그램의 폴더에 저장할 수 있습니다. 폴더는 캐릭터나 비교 목적별로 만들 수 있으며, 저장한 장비 세트는 환산기 아이템메이커에 적용할 수 있습니다.

### 스펙업 순서 분석

환산기 스펙업 순서 화면에서 조회된 데이터를 바탕으로 목표 최종뎀, 교환불가 가중치, 조각 가격, 환불 가격을 반영해 우선순위를 계산합니다. 교환불가 항목에만 설정한 가중치를 적용하며, 분석 결과와 분석 시각은 팝업을 다시 열어도 확인할 수 있도록 로컬에 보관합니다. 기준선에 해당하는 항목은 환산기 화면에서 강조 표시합니다.

## 동작 구조

이 프로젝트는 Chrome Extension Manifest V3 기반의 확장 프로그램입니다.

1. 경매장과 환산기 페이지에서 콘텐츠 스크립트가 동작합니다.
2. 경매장 측 데이터는 확장 프로그램 저장소에 보관되고, 선택한 항목은 `mapper.js`가 환산기 아이템메이커의 장비 형식으로 변환합니다.
3. 백그라운드 서비스 워커가 환산기 탭을 열고, 페이지 문맥에서 아이템메이커 보관 목록을 갱신합니다.
4. 팝업은 찜 목록, 장비 보관함, 스펙업 순서의 세 영역에서 저장된 데이터와 분석 결과를 보여 줍니다.
5. 백그라운드 서비스 워커는 설치 시와 60분 주기마다 원격 설정을 갱신하고, 팝업은 이를 사용해 업데이트 안내·기능 비활성화·공지 배너를 표시할 수 있습니다.

## 데이터와 저장 위치

| 데이터 | 저장 위치 | 용도 |
| --- | --- | --- |
| 경매장 찜 목록 | `chrome.storage.local` | 선택·정리·내보내기할 장비 목록 |
| 확장 프로그램 보관함 폴더 | `chrome.storage.local` | 캐릭터 또는 목적별 장비 세트 |
| 스펙업 분석 설정·수집 데이터·마지막 결과 | `chrome.storage.local` | 분석 조건, 환산기에서 읽은 데이터, 마지막 분석 결과와 분석 시각 |
| 원격 설정 | `chrome.storage.local` | 업데이트 안내, 기능별 임시 비활성화, 공지 배너 표시 기준 |
| 아이템메이커 보관 목록 | 환산기 페이지의 브라우저 로컬 저장소 | 환산기에서 사용하는 장비 보관 데이터 |

## 지원 범위와 제한 사항

- 이 확장 프로그램은 메이플스토리 웹 경매장과 MapleScouter 웹사이트의 현재 화면·데이터 형식을 전제로 동작합니다. 두 서비스의 UI나 데이터 형식이 바뀌면 일부 기능이 동작하지 않을 수 있습니다.
- 경매장 찜 목록은 해당 페이지를 방문한 뒤에 동기화됩니다. 페이지를 방문하지 않았거나 대상 슬롯이 없으면 팝업에서 빈 목록으로 보일 수 있습니다.
- 장비 보관함을 환산기 아이템메이커에 **교체**하는 작업은 대상 보관 목록을 덮어쓸 수 있습니다. 확인 창의 내용을 읽고 필요한 데이터는 먼저 보관하세요.
- 분석 결과는 입력한 목표값과 가격·가중치를 기준으로 정리한 참고 정보입니다. 게임 내 실제 비용이나 결과를 보장하지 않습니다.
- 원격 설정을 통해 특정 기능이 임시로 비활성화되거나 업데이트 안내가 표시될 수 있습니다. 외부 사이트 변경으로 인한 잘못된 동작을 줄이기 위한 보호 장치입니다.
- 본 프로젝트는 넥슨 및 MapleScouter와 무관한 개인 프로젝트입니다. 사용 결과와 데이터 관리의 책임은 사용자에게 있습니다.

## 용어

| 용어 | 의미 |
| --- | --- |
| 환산기 | MapleScouter 웹사이트를 가리키는 문서 내 표현 |
| 아이템메이커 | 환산기에서 장비 데이터를 보관·비교하는 기능 |
| 찜 목록 | 메이플스토리 웹 경매장에서 사용자가 찜한 장비 목록 |
| 보관함 | 확장 프로그램에 저장하는 장비 세트와 폴더 |
| 내보내기 | 선택한 찜 목록 장비를 환산기 아이템메이커에 추가하는 작업 |
| 교체 | 보관함에 저장한 장비 세트로 환산기 아이템메이커 목록을 바꾸는 작업 |
