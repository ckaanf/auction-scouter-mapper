# 릴리스 노트

## v1.1.2 — 스펙업 분석 결과 유지 및 교환가능 항목 보정

스펙업 순서 분석 화면의 사용 흐름과 비용 계산을 보완한 핫픽스입니다.

- 분석이 완료되면 결과와 분석 시각을 확장 프로그램의 로컬 저장소에 보관합니다. 팝업을 닫았다가 다시 열어도 마지막 분석 결과를 확인할 수 있습니다.
- **스펙업 순서** 분석 실행 버튼은 MapleScouter의 스펙업 순서 페이지에서만 동작하도록 확인 절차를 추가했습니다.
- 교환가능 장비의 비용·효율은 원본 값을 그대로 사용합니다. 교환불가 항목에만 사용자가 설정한 **교환불가 가중치**를 적용합니다.
- 추가옵션 항목의 비용은 산정 검증 전까지 결과 화면에 **검증 중**으로 표시합니다. 비용이 확인되기 전에는 총 필요 기댓값에 합산되지 않습니다.

## v1.1.1 — 교환불가 가중치와 북마크 대상 검증

- 교환불가 장비, 심볼, 북마크에 교환불가 가중치를 반영해 우선순위를 계산합니다.
- 교환불가 장비의 종류별 결과를 함께 읽어 분석 대상에서 누락되지 않도록 개선했습니다.
- 현재 조회 중인 캐릭터의 북마크만 분석에 포함합니다. 다른 캐릭터의 북마크는 결과에 섞이지 않습니다.
- 무료이거나 비용이 0인 심볼 항목도 분석 목록에서 빠지지 않도록 보완했습니다.

## 참고 사항

- 마지막 분석 결과는 현재 브라우저 프로필의 `chrome.storage.local`에 저장됩니다. 확장 프로그램 데이터를 삭제하면 함께 삭제됩니다.
- 저장된 결과는 당시 환산기에서 읽은 데이터와 설정값을 바탕으로 한 참고용 기록입니다. 최신 정보가 필요하면 MapleScouter의 스펙업 순서 페이지에서 다시 분석해 주세요.
- 분석 결과와 비용은 게임 내 실제 비용 또는 거래 결과를 보장하지 않습니다.
