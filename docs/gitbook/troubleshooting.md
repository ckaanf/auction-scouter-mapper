# 문제 해결과 제한 사항

## 찜 목록이 비어 있어요

1. 메이플스토리 웹 경매장의 **찜 목록** 페이지를 다시 방문합니다.
2. 새로고침한 뒤 확장 프로그램 팝업을 다시 엽니다.
3. 찜한 항목이 환산 계산 대상 장비 슬롯인지, 현금 아이템이 아닌지 확인합니다.

## 캐릭터를 찾을 수 없다고 나와요

1. 입력한 캐릭터명을 다시 확인합니다.
2. 환산기에서 해당 캐릭터를 정상적으로 조회할 수 있는지 확인합니다.
3. 잠시 뒤 다시 시도합니다. 외부 API 응답 상태에 따라 조회에 실패할 수 있습니다.

## 환산기 탭이 열렸지만 목록이 기대와 달라요

1. 주입 대상과 선택한 장비 수를 먼저 확인합니다.
2. 환산기 아이템메이커 화면을 새로고침해 결과를 확인합니다.
3. 동일한 항목을 여러 번 추가했을 수 있으니 보관 목록을 확인합니다.
4. 외부 사이트가 업데이트된 직후라면 데이터 형식 또는 화면 구조가 바뀌었을 수 있습니다.

## 보관함 세트를 적용했더니 기존 항목이 사라졌어요

보관함 세트를 **교체**하는 작업은 환산기 아이템메이커의 기존 목록을 선택한 세트로 바꿉니다. 확인 창이 뜰 때 대상 폴더와 장비 수를 확인하세요. 필요한 목록은 교체 전에 확장 프로그램 보관함의 다른 폴더에 저장해 두는 것을 권장합니다.

## 스펙업 분석 결과가 비어 있거나 강조가 안 보여요

1. 환산기 사이트에서 스펙업 순서를 먼저 조회합니다.
2. 페이지를 새로고침한 뒤 분석을 다시 실행합니다.
3. 목표 최종뎀과 가격·가중치 값이 숫자로 입력됐는지 확인합니다.
4. 환산기 UI가 변경된 경우 강조 표시가 보이지 않을 수 있습니다.

## 기능이 임시 점검 중이거나 업데이트 안내가 보여요

외부 사이트의 변경 또는 호환성 문제로 기능이 일시적으로 비활성화될 수 있습니다. 확장 프로그램을 최신 버전으로 업데이트하고, 팝업의 공지 내용을 확인해 주세요. 이 안내는 잘못된 데이터 처리나 반복 오류를 줄이기 위한 보호 장치입니다.

## 알려진 제한 사항

- 이 확장 프로그램은 메이플스토리 웹 경매장과 MapleScouter의 현재 페이지 구조와 데이터 형식에 의존합니다.
- 확장 프로그램 데이터는 브라우저의 로컬 저장소에 저장됩니다. 브라우저 프로필·기기 간 자동 동기화는 지원하지 않습니다.
- 원격 설정 갱신에는 네트워크 상태와 최대 60분의 갱신 주기가 영향을 줄 수 있습니다.
- 분석은 입력값을 바탕으로 한 참고 정보이며, 실제 비용·성공 확률·게임 결과를 보장하지 않습니다.

## 면책 조항

본 프로젝트는 넥슨 및 MapleScouter와 무관한 개인 프로젝트입니다. 소프트웨어 사용으로 발생하는 결과와 데이터 관리의 책임은 사용자에게 있습니다.
