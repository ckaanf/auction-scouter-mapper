# 시작하기

## 준비물

- Google Chrome 또는 Chromium 기반 브라우저
- 압축을 푼 이 확장 프로그램 폴더
- 메이플스토리 웹 경매장과 MapleScouter 웹사이트에 접근할 수 있는 브라우저 탭

## 설치하기

1. 주소창에 `chrome://extensions/`를 입력해 확장 프로그램 관리 페이지를 엽니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 프로젝트 폴더를 선택합니다.
5. 브라우저 도구 모음에서 **메이플 환산 아이템메이커 브릿지** 아이콘을 고정하면 사용하기 편합니다.

![확장 프로그램 설치 화면](../assets/screenshots/01-extension-install.png)

스크린샷이 아직 준비되지 않았다면 [촬영 체크리스트](../assets/screenshots/README.md)를 확인하세요.

## 처음 사용할 때

1. 메이플스토리 웹 경매장의 **찜 목록** 페이지를 한 번 방문합니다.
2. 확장 프로그램 아이콘을 열고 **경매장 찜 목록** 탭을 확인합니다.
3. 목록이 보이면 [찜 목록을 환산기에 추가하는 방법](auction-to-item-maker.md)을 진행합니다.

## 알아둘 점

- 확장 프로그램은 경매장 찜 목록 페이지를 방문했을 때 목록을 동기화합니다. 방문 전에는 팝업이 비어 있을 수 있습니다.
- 환산 계산 대상이 아닌 슬롯과 현금 아이템은 가져오지 않습니다.
- 외부 사이트의 UI 또는 데이터 형식이 변경되면 동작하지 않을 수 있습니다. 문제가 있으면 [문제 해결과 제한 사항](troubleshooting.md)을 확인하세요.
