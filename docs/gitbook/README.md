# 메이플 환산 아이템메이커 브릿지 사용자 가이드

경매장 찜 목록을 환산기 아이템메이커로 옮기고, 장비 세트와 스펙업 분석을 관리하는 Chrome 확장 프로그램 안내서입니다.

## 목차

1. [시작하기](getting-started.md)
2. [경매장 찜 목록을 환산기에 추가하기](auction-to-item-maker.md)
3. [장비 보관함 사용하기](storage.md)
4. [스펙업 순서 분석하기](spec-order.md)
5. [문제 해결과 제한 사항](troubleshooting.md)
6. [릴리스 노트](release-notes.md)

## 빠른 흐름

1. 확장 프로그램을 설치합니다.
2. 메이플스토리 웹 경매장 찜 목록을 방문합니다.
3. 확장 프로그램의 **경매장 찜 목록** 탭에서 장비를 선택해 환산기에 추가합니다.
4. 필요하면 환산기 장비를 **환산 메이커 보관함**에 캐릭터별로 저장합니다.
5. 환산기 스펙업 순서 화면을 조회한 뒤 **스펙업 순서** 탭에서 분석 조건을 적용합니다.

> 이 프로젝트는 넥슨 및 MapleScouter와 무관한 개인 프로젝트입니다. 외부 사이트의 화면 또는 데이터 형식 변경에 따라 기능이 달라질 수 있습니다.
