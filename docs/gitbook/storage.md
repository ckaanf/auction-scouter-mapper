# 장비 보관함 사용하기

## 이 기능으로 할 수 있는 일

환산기에서 장비 세트를 가져와 확장 프로그램에 저장하고, 캐릭터·비교 목적별 폴더로 관리합니다. 저장한 세트는 환산기 아이템메이커에 다시 적용할 수 있습니다.

## 시작 전 확인

- 환산기 사이트를 열어 둡니다.
- 데이터를 구분할 폴더 이름을 정합니다. 예: `본캐 섀도어`, `앱솔 비교`
- 기존 아이템메이커 데이터를 교체할 경우, 필요한 목록을 먼저 확인하거나 별도로 보관합니다.

## 사용 방법

### 장비를 보관함으로 가져오기

1. 확장 프로그램의 **환산 메이커 보관함** 탭을 엽니다.
2. 현재 캐릭터의 장비를 가져오려면 **내 장비 불러오기**를, 환산기 아이템메이커 목록을 가져오려면 **보관함 불러오기**를 누릅니다.
3. 가져온 장비 중 보관할 항목을 선택합니다.
4. 기존 폴더를 선택하거나 **새 폴더 만들어 이동**을 선택합니다.
5. 필요하면 상단 입력란에 폴더 이름을 적고 **폴더 추가**를 누릅니다.
6. **이동 실행**을 눌러 선택한 장비를 저장합니다.

### 저장한 세트를 환산기에 적용하기

1. 보관함 폴더를 열어 적용할 장비 세트를 확인합니다.
2. 해당 세트를 환산기 아이템메이커로 보내는 동작을 선택합니다.
3. 교체 확인 창이 표시되면 대상과 장비 개수를 확인합니다.
4. 동의하면 환산기 탭에서 저장한 세트로 목록이 갱신됩니다.

## 성공 확인

- 폴더 제목에 저장된 장비 수가 표시됩니다.
- 환산기에서 적용한 경우 아이템메이커 보관 목록이 선택한 세트로 보입니다.

## 주의 사항

- **교체**는 환산기 아이템메이커의 기존 보관 목록을 덮어쓸 수 있습니다. 확인 창을 취소하면 교체하지 않습니다.
- 폴더 삭제나 장비 삭제는 확장 프로그램 보관함에 저장된 데이터를 제거합니다.
- 이 기능은 브라우저의 로컬 저장소를 사용하므로 다른 브라우저 프로필이나 기기에는 자동 동기화되지 않습니다.

## 관련 문제 해결

캐릭터를 찾지 못하거나 보관함 불러오기에 실패하면 [문제 해결과 제한 사항](troubleshooting.md)을 확인하세요.
