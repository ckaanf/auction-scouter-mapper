# 스펙업 순서 분석하기

## 이 기능으로 할 수 있는 일

환산기에서 조회한 스펙업 순서 데이터를 바탕으로 목표 최종뎀과 비용 조건을 반영해 우선순위를 정리하고, 기준선에 해당하는 항목을 환산기 화면에서 강조합니다.

## 시작 전 확인

- 환산기 사이트에서 스펙업 순서를 먼저 조회해야 합니다.
- 확장 프로그램 팝업의 **스펙업 순서** 탭을 열 수 있어야 합니다.
- 가격과 가중치는 본인의 판단 기준으로 입력합니다. 실제 비용을 보장하는 값이 아닙니다.

## 사용 방법

1. 환산기 사이트에서 스펙업 순서를 조회합니다.
2. 확장 프로그램을 열고 **스펙업 순서** 탭으로 이동합니다.
3. 다음 조건을 입력합니다.
   - **목표 최종뎀**: 분석에서 달성하려는 최종뎀 상승 목표
   - **교환불가 가중치**: 교환불가 항목 비용에 적용할 배수
   - **조각 가격**: 헥사 관련 비용을 계산할 때 쓸 조각 가격
   - **환불 가격**: 추가옵션 비용 보정에 쓸 환불 가격
4. **설정 적용 및 분석 실행**을 누릅니다.
5. 팝업의 결과 목록에서 항목·예상 비용·상승량을 확인합니다.
6. 환산기 탭에서 강조 표시된 기준선 항목을 함께 확인합니다.

## 결과를 다시 확인하려면

분석을 실행하면 마지막 결과와 분석 시각이 이 브라우저의 확장 프로그램 로컬 저장소에 저장됩니다. 팝업을 닫았다가 열어도 결과를 다시 볼 수 있습니다.

- 분석은 MapleScouter의 **스펙업 순서** 페이지에서만 실행할 수 있습니다.
- 저장된 결과는 분석 당시의 환산기 데이터와 설정값을 보여 줍니다. 현재 상태를 기준으로 다시 계산하려면 해당 페이지에서 분석을 다시 실행해 주세요.
- 브라우저에서 확장 프로그램 데이터를 삭제하면 저장된 결과도 삭제됩니다.

## 성공 확인

- 팝업에 목표 최종뎀, 적용한 조건, 정리된 분석 결과가 표시됩니다.
- 환산기 화면에서 기준선에 해당하는 장비·심볼·헥사 항목이 강조될 수 있습니다.

## 주의 사항

- 분석은 환산기에서 읽은 현재 데이터와 입력한 조건을 사용합니다.
- 교환불가 항목에만 **교환불가 가중치**가 적용됩니다. 교환가능 장비는 원본 비용과 효율을 기준으로 계산합니다.
- 추가옵션 비용은 원본 기대값을 기준값으로 나눠 시행 횟수로 환산한 뒤, 입력한 환불 가격과 교환불가 가중치를 반영합니다.
- 조각 가격과 환불 가격은 입력 단위를 확인해 주세요. 화면에는 만 단위로 표시됩니다.
- 분석 결과는 투자 판단을 돕는 참고 정보이며, 게임 내 결과나 실제 거래 가격을 보장하지 않습니다.

## 관련 문제 해결

분석 결과가 비어 있거나 강조가 보이지 않으면 [문제 해결과 제한 사항](troubleshooting.md)을 확인하세요.
