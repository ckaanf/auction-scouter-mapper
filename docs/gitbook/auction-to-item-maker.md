# 경매장 찜 목록을 환산기에 추가하기

## 이 기능으로 할 수 있는 일

메이플스토리 웹 경매장에서 찜한 장비 중 원하는 항목을 골라 MapleScouter의 아이템메이커 보관 목록에 추가합니다.

## 시작 전 확인

- 확장 프로그램이 설치되어 있어야 합니다.
- 메이플스토리 웹 경매장의 **찜 목록** 페이지를 먼저 방문해야 합니다.
- 환산기 탭을 열 수 있어야 합니다.

## 사용 방법

1. 확장 프로그램을 열고 **경매장 찜 목록** 탭으로 이동합니다.
2. 목록에서 비교할 장비를 체크합니다. 필요하면 **전체 선택**을 사용합니다.
3. 판매가 종료되었거나 찜이 해제된 항목은 상태 표시를 확인한 뒤 선택합니다.
4. **환산 사이트로 바로 추가하기**를 누릅니다.
5. 캐릭터 조회·확인 절차가 표시되면 대상 캐릭터가 맞는지 확인합니다.
6. 환산기 아이템메이커 탭이 열리면 주입 결과를 확인합니다.

![찜 목록 선택과 내보내기](../assets/screenshots/02-wishlist-export.png)

## 성공 확인

- 환산기 아이템메이커 보관 목록에 선택한 장비가 추가됩니다.
- 확장 프로그램의 찜 목록은 그대로 유지되므로 다른 조합도 이어서 비교할 수 있습니다.

## 주의 사항

- 이 작업은 아이템메이커 목록에 장비를 **추가**합니다. 기존 목록을 정리하려면 환산기에서 내용을 먼저 확인하세요.
- 팝업의 **선택된 품목 삭제**와 **전체 품목 삭제**는 확장 프로그램에 저장된 찜 목록을 지웁니다.
- 현금 아이템과 지원하지 않는 슬롯은 동기화되지 않습니다.

## 관련 문제 해결

목록이 비어 있거나 환산기 탭이 열리지 않으면 [문제 해결과 제한 사항](troubleshooting.md)을 확인하세요.
