# 스크린샷 촬영 체크리스트

가이드는 이미지 없이도 이해되어야 합니다. 아래 이미지는 본문을 보조하고 실제 화면 위치를 빠르게 찾게 하는 용도입니다.

| 파일명 | 촬영 시점 | 사용 문서 | 권장 캡션 | 마스킹할 정보 |
| --- | --- | --- | --- | --- |
| `01-extension-install.png` | Chrome 확장 프로그램 관리 화면에서 개발자 모드와 압축 해제 로드 버튼이 보일 때 | 시작하기 | 개발자 모드에서 확장 프로그램 로드 | 로컬 폴더 경로 |
| `02-wishlist-export.png` | 경매장 찜 목록 탭에서 장비 선택과 내보내기 버튼이 보일 때 | 찜 목록을 환산기에 추가하기 | 선택한 찜 목록을 환산기로 추가 | 캐릭터명, 실제 거래 가격·식별 정보 |
| `03-storage.png` | 보관함 탭에서 폴더와 가져온 장비 목록이 보일 때 | 장비 보관함 사용하기 | 장비를 폴더에 저장하고 세트 관리 | 캐릭터명, 장비 식별 정보 |
| `04-spec-order.png` | 스펙업 순서 탭에서 네 입력값과 분석 결과가 보일 때 | 스펙업 순서 분석하기 | 조건을 적용해 우선순위 확인 | 캐릭터명, 민감한 비용·계정 정보 |
| `05-item-maker-result.png` | 환산기 아이템메이커에서 주입 결과가 보일 때 | 찜 목록을 환산기에 추가하기 | 환산기에서 추가된 장비 확인 | 캐릭터명, 보관 목록의 개인 정보 |

이미지는 이 폴더에 저장하고, 게시 전에는 캐릭터명·계정 정보·실거래 정보가 드러나지 않는지 다시 확인합니다.
