+
메이플스토리 웹 경매장의 찜 목록 장비를 MapleScouter 아이템메이커 형식으로 변환해 비교 과정을 줄이는 Chrome 확장 프로그램입니다.

## 왜 만들었나요?

경매장에서 장비를 찾은 뒤 환산기에 같은 정보를 반복 입력하는 흐름을 줄이고 싶었습니다. 찜 목록에서 후보를 고른 뒤 바로 아이템메이커에 추가하고, 캐릭터별 장비 세트와 스펙업 분석까지 한곳에서 관리하는 것을 목표로 했습니다.

## 핵심 기능

- 경매장 찜 목록에서 환산 계산 대상 장비를 동기화하고 선택 항목을 환산기 아이템메이커에 추가
- 환산기 장비·아이템메이커 목록을 가져와 캐릭터 또는 목적별 폴더에 보관
- 목표 최종뎀, 교환불가 가중치, 조각·환불 가격을 반영한 스펙업 순서 분석
- 판매 종료·찜 해제 상태 표시와 선택/전체 삭제를 통한 찜 목록 정리

## 어떻게 동작하나요?

경매장과 환산기 페이지의 콘텐츠 스크립트가 필요한 데이터를 읽고, 팝업이 이를 선택·보관·분석할 수 있게 합니다. 경매장 장비는 `mapper.js`에서 아이템메이커 형식으로 변환되며, 백그라운드 서비스 워커가 환산기 탭을 열어 보관 목록을 갱신합니다.

자세한 데이터 흐름과 제한 사항은 [제품 개요](docs/product-overview.md)에서 확인할 수 있습니다.

## 기술적 포인트

- Chrome Extension Manifest V3와 서비스 워커 기반의 탭·스크립트 제어
- 콘텐츠 스크립트와 페이지 문맥의 연결을 통한 외부 웹앱 데이터 연동
- `chrome.storage.local`로 찜 목록, 보관함 폴더, 분석 설정을 로컬 관리
- 직업군별 유효 스탯 필터링과 아이템 옵션 구조 변환
- Jest 기반 단위 테스트로 매퍼와 백그라운드 메시지 흐름 검증
