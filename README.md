# 메이플스토리 경매장 - 환산기 연동 브릿지

메이플스토리 웹 경매장의 찜 목록 아이템 데이터를 추출하여, 환산 주스탯(MapleScouter) 사이트의 '아이템 메이커' 규격으로 자동 변환 및 주입하는 크롬 확장 프로그램입니다.
또한 환산 주스탯 사이트의 다른 캐릭터의 착용 장비를 빠르게 가져오고 익스텐션 내의 보관함을 통해 보관할 수 있습니다.

이 기능은, 다양한 캐릭터를 키우는 유저들과, 시뮬레이션을 더 편하게 하고 싶은 저를 위해 개발했습니다.

## ⚠️ Disclaimer (면책 조항)
**본 프로젝트는 넥슨(메이플스토리) 및 환산기 서비스와 무관한 개인 연구용 익스텐션입니다.** 본 소프트웨어 사용으로 인해 발생하는 모든 문제와 결과에 대한 책임은 전적으로 사용자 본인에게 있습니다.

## 📖 사용자 가이드
*(이곳에 본인의 사용법을 간략히 추가하세요)*
1. 크롬 익스텐션 관리 페이지(`chrome://extensions/`)에서 개발자 모드를 켜고 압축을 해제한 폴더를 로드합니다.
2. 메이플스토리 웹 경매장에서 아이템을 찜합니다.
3. 익스텐션을 열어 아이템을 선택하고 환산기 사이트로 주입합니다.
